# DB Sprint · 数据库系统概论全书速通

这是一个本地可运行的全书速通学习网页，基于《数据库系统概论（第 6 版）》制作。第一章保留了已确认的样板内容，第二章至第十八章按照教材目录接入章节地图、一级小节知识点、速通解释和练习入口。

## 本地运行

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可学习。

## 验证命令

```bash
npm test -- --run
npm run build
```

## 已实现

- 首页继续学习入口与全书 18 章课程地图
- 章 → 小节 → 知识点三级目录，按教材原始顺序组织
- 第一章 17 个知识点原样保留；全书共 102 个速通知识点

## 内容边界

网页采用“一级小节作为学习单元”的速通组织方式，不把 500 页教材逐字搬入页面。教材目录映射标记为“教材内容”；为了帮助理解而提炼的解释、关系、流程和练习标记为“教材补充”或“Agent补充题”。这套结构适合继续追加章节细节、实验和更多原题。

不包含账号、云同步、AI 助手、排行榜、打卡、社区或公网部署。

## GitHub Pages

仓库已包含 GitHub Actions 构建与 Pages 部署工作流。若要启用公开页面，在仓库 Settings → Pages 中将构建来源设为 GitHub Actions，然后在 Settings → Secrets and variables → Actions → Variables 添加 `PAGES_ENABLED=true`，再重新运行工作流。当前连接无法代替仓库管理员修改 Pages 设置，因此代码已推送、CI 构建可直接运行，Pages 部署保留为可启用步骤。
